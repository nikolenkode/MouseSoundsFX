# Mouse Sound FX

Mouse Sound FX — это десктопное приложение для настройки звукового отклика на клики мыши. Проект построен на строгом разделении логики и представления: бизнес-логика работает в чистом Python (`backend/`), а пользовательский интерфейс реализован на HTML/CSS/JS (`web/`).

Окно приложения нативное и работает без отдельного браузера. Связь обеспечивает библиотека [pywebview](https://pywebview.flowrl.com/?utm_source=gemini) — она открывает системный веб-движок (WebView2 на Windows, WebKit на macOS, GTK-WebKit на Linux) и безопасно пробрасывает Python-объект `Api` в JavaScript как `window.pywebview.api`. Окно полностью безрамочное, с собственной шапкой, кнопками управления и возможностью перетаскивания за логотип.

## 📂 Структура проекта

```text
main.py                  — точка входа: окно, проверка WebView2, связка с Api
backend/
  paths.py               — пути к ресурсам (с учётом особенностей PyInstaller)
  colors.py              — цветовая математика (blend/lighten/hsv/clamp)
  constants.py           — звуковые паки, пресеты темы, дефолтный конфиг
  config.py              — чтение/запись config.json с валидацией
  sound_library.py       — загрузка и кэширование звуков (pygame)
  api.py                 — вся логика приложения и мост к JS
web/
  index.html             — разметка
  style.css              — вся визуальная часть и анимации
  app.js                 — вызовы api.*, перерисовка из состояния

```

**Архитектурный принцип:** `app.js` ничего не вычисляет самостоятельно. Он считывает действия пользователя, вызывает соответствующий метод `api.*` и перерисовывает экран на основе состояния, которое возвращает Python. Вся логика (валидация, сохранение конфига, расчет цветов) строго изолирована в `backend/`.

## 🛠 Установка зависимостей

Установите необходимые пакеты командой:

```bash
python -m pip install -r requirements.txt

```

*Используйте `python -m pip`, а не просто `pip`. При наличии нескольких версий Python в системе голый `pip` может установить пакеты в другое окружение. Для проверки правильности установки выполните: `python -c "import webview, pygame, pynput; print('OK')"`.*

### Платформенные зависимости

* **Windows**: Требуются два системных компонента:
1. **WebView2 Runtime** — обычно предустановлен на Windows 10/11. Если его нет, установите [Evergreen Bootstrapper от Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/?utm_source=gemini).
2. **pythonnet** — пакет, необходимый `pywebview` для связи с WebView2. Устанавливается автоматически через `requirements.txt` (зависимость `pywebview[winforms]`).
*Приложение автоматически проверяет наличие обоих компонентов при старте. В случае отсутствия выводится окно с понятной ошибкой.*


* **Linux**: Требуются системные пакеты GTK/WebKit.
* **macOS**: Работает из коробки.

## ⚠️ Добавление звуков (Перед первым запуском)

В репозитории содержится только исходный код, звуковые файлы не включены в состав проекта.
Для корректной работы создайте в корне проекта (рядом с `main.py`) папку `sounds` и разместите в ней свои `.wav` файлы по следующей структуре (по 6 файлов на каждый пак):

* `sounds/soft/`
* `sounds/sharp/`
* `sounds/deep/`
* `sounds/custom/` (для пользовательских звуков)

*Без этих файлов приложение запустится, но воспроизводить звуки не будет.* При первом запуске также будет автоматически сгенерирован файл настроек `config.json`.

## 🚀 Запуск

Для стандартного запуска:

```bash
python main.py

```

Для запуска с выводом отладочной информации:

```bash
python main.py --debug

```

## 📦 Сборка в `.exe` (Для Windows)

Для автоматической сборки запустите **`build.bat`**.
Скрипт самостоятельно установит PyInstaller, удалит кэш от предыдущих сборок (`build/` и `dist/`) и соберёт приложение с нужными флагами.

### Ручная сборка

```bash
python -m pip install pyinstaller
python -m PyInstaller --clean --noconfirm --windowed --name "Mouse Sound FX" ^
  --add-data "web;web" --add-data "sounds;sounds" ^
  --collect-submodules webview --collect-submodules clr_loader --collect-submodules pythonnet ^
  --hidden-import pynput.mouse._win32 --hidden-import pynput.keyboard._win32 ^
  main.py

```

Флаги `--collect-submodules` и `--hidden-import` обязательны. Библиотеки `pywebview` и `pynput` подгружают платформенный бэкенд динамически. Без этих флагов собранный `.exe` не будет работать (и не выдаст ошибок в консоль).

* **Linux/macOS:** В параметре `--add-data` используйте `:` вместо `;`. Специфичные для Windows флаги (`clr_loader`, `pythonnet`, `_win32`) указывать не нужно.

**Результат:** Готовый билд появится в папке `dist/Mouse Sound FX/`. **Для запуска и дистрибуции требуется вся папка целиком**, так как рядом с `.exe` находятся обязательные `.dll` библиотеки и ресурсы (папки `web` и `sounds`).

## 🔧 Частые проблемы при разработке

Если после изменения кода поведение приложения не поменялось:

1. **Собран старый кэш.** При ручной сборке PyInstaller может закешировать файлы. Обязательно удаляйте папки `build/` и `dist/` перед новой сборкой (скрипт `build.bat` делает это автоматически).
2. **Висит старый процесс.** Приложение могло остаться в фоне. Откройте Диспетчер задач, найдите "Mouse Sound FX" и завершите процесс перед новым запуском или сборкой.

## 🪟 Технические детали интерфейса

### Окно без рамки и перетаскивание

* Захват и перетаскивание окна осуществляется за область логотипа слева, на которой установлен CSS-класс `.pywebview-drag-region`.
* Кнопки управления окном (свернуть/закрыть) реализованы через вызовы `Api.minimize_window()` и `Api.close_window()`.
* Перетаскивание работает благодаря комбинации параметра `easy_drag=True` (при создании окна в Python) и предварительной конфигурации `webview.settings["DRAG_REGION_SELECTOR"] = ".pywebview-drag-region"`. Установка `easy_drag=False` с тем же селектором полностью отключает перетаскивание. Не назначайте класс `.pywebview-drag-region` на кликабельные элементы интерфейса.

### Графика и слои (CSS/SVG)

* **Формы и градиенты:** Используются нативные CSS-свойства (`border-radius`, `linear-gradient`) без сложных математических вычислений в коде.
* **Узоры фона:** Реализованы через SVG `<pattern>` в отдельном слое. Доступно 7 вариантов (соты, волны, ромб, точки, сетка, диагональные полосы, без узора).
* **Стекинг:** Слой узора имеет `position: absolute`. Чтобы узор не перекрывал интерфейс интерфейсу, слою задан `z-index: -1`, а основным контейнерам (`.stage`, `.panel`) — `z-index: 0` для создания локального контекста наложения.

### Анимации

Все визуальные эффекты работают на чистом CSS (`@keyframes` и `transition`), JavaScript отвечает только за переключение классов:

* Плашки интерфейса появляются каскадно при запуске (за счет `animation-delay`).
* Кнопка питания плавно пульсирует в активном состоянии.
* Навигация и выбор элементов сопровождаются легким масштабированием интерфейса ("поп-эффект"). Кнопки тактильно "проседают" при нажатии.
* Клик по кнопке воспроизведения генерирует расходящееся кольцо поверх вспышки.
* Приложение поддерживает системную настройку ОС "Уменьшить движение" (`prefers-reduced-motion`) — при её активации анимации автоматически минимизируются.
