# Mouse Sound FX

Легковесное десктопное приложение для настройки звукового отклика на клики мыши. Никаких встроенных Chromium-монстров — интерфейс работает в нативном окне.

Под капотом используется Python (`backend/`) для бизнес-логики и HTML/CSS/JS (`web/`) для UI. Они общаются через библиотеку [pywebview](https://pywebview.flowrl.com/?utm_source=gemini), которая поднимает системный веб-движок (WebView2 на Windows, WebKit на macOS, GTK-WebKit на Linux) и прокидывает Python-объект в JavaScript. Окно полностью безрамочное, со своей кастомной шапкой и кнопками управления.

## Структура проекта

```text
main.py                  — точка входа: инициализация окна, проверка WebView2
backend/
  paths.py               — пути к ресурсам (с фиксом для PyInstaller)
  colors.py              — цветовая математика (blend/lighten/hsv/clamp)
  constants.py           — дефолтный конфиг, пресеты тем, паки звуков
  config.py              — чтение/запись config.json с валидацией
  sound_library.py       — загрузка и кэширование звуков через pygame
  api.py                 — основная логика и мост для JS
web/
  index.html             — разметка
  style.css              — визуал и анимации
  app.js                 — вызовы api.* и рендер состояния

```

**Как это работает:** Фронт здесь максимально «глупый». `app.js` просто ловит события, дергает нужный метод `api.*` и перерисовывает DOM на основе того, что ответил Python. Вся валидация, сохранение настроек и расчет цветов жестко изолированы на бэкенде.

## Установка зависимостей

```bash
python -m pip install -r requirements.txt

```

*(Лучше использовать именно `python -m pip`, чтобы при наличии нескольких версий Python пакеты улетели в правильное окружение. Проверить, что всё завелось: `python -c "import webview, pygame, pynput; print('OK')"`).*

**Нюансы по платформам:**

* **Windows**: Для работы нужны WebView2 Runtime (на Win 10/11 обычно уже стоит) и питоновский пакет `pythonnet` (подтянется из requirements). Скрипт сам проверит их наличие при старте и, если чего-то не хватает, покажет нормальное окно с ошибкой, а не упадет втихую.
* **Linux**: Потребуются системные пакеты GTK/WebKit.
* **macOS**: Работает из коробки.

## Подготовка (важно перед первым запуском!)

В репозитории лежит только код. Сами звуковые файлы нужно добавить вручную. Создайте папку `sounds/` рядом с `main.py` и раскидайте туда `.wav` файлы (по 6 штук на пак):

* `sounds/soft/`
* `sounds/sharp/`
* `sounds/deep/`
* `sounds/custom/` (если есть свои кастомные звуки)

Без этих файлов приложение запустится, но звука не будет. Файл `config.json` сгенерируется сам при первом старте.

## Запуск

Обычный запуск:

```bash
python main.py

```

С выводом дебаг-логов в консоль:

```bash
python main.py --debug

```

## Сборка в .exe (Windows)

Самый простой вариант — запустить **`build.bat`**. Он сам поставит PyInstaller, снесет старые билды (`build/` и `dist/`, чтобы не было кэша) и соберет всё с нужными флагами.

Если хотите собрать руками:

```bash
python -m pip install pyinstaller
python -m PyInstaller --clean --noconfirm --windowed --name "Mouse Sound FX" ^
  --add-data "web;web" --add-data "sounds;sounds" ^
  --collect-submodules webview --collect-submodules clr_loader --collect-submodules pythonnet ^
  --hidden-import pynput.mouse._win32 --hidden-import pynput.keyboard._win32 ^
  main.py

```

**Почему такие флаги:** `pywebview` и `pynput` подтягивают платформенные либы динамически. Статический анализ PyInstaller их не видит. Без флагов `--collect-submodules` и `--hidden-import` экзешник скомпилируется, но работать не будет (причем без единой ошибки в логе).

*Для Linux/macOS:* В `--add-data` меняем `;` на `:`. Виндовые флаги (`clr_loader`, `pythonnet`, `_win32`) убираем.

**Итог:** Готовый билд лежит в `dist/Mouse Sound FX/`. **Для работы нужна вся эта папка**, а не только .exe. Рядом с ним лежат нужные dll-ки и ресурсы.

## Если после правок кода ничего не меняется

1. **Закешировался старый билд.** PyInstaller любит кэшировать файлы. Всегда удаляйте `build/` и `dist/` перед новой сборкой (в `build.bat` это автоматизировано).
2. **Завис процесс.** Приложение могло остаться висеть в фоне. Зайдите в Диспетчер задач, прибейте "Mouse Sound FX" и попробуйте снова.

## Детали по UI

* **Кастомное перетаскивание окна:** Повешено на логотип слева (через класс `.pywebview-drag-region`). Чтобы это работало, в Python нужно включить `easy_drag=True` И прописать `webview.settings["DRAG_REGION_SELECTOR"] = ".pywebview-drag-region"`. Установка `easy_drag=False` ломает таскание полностью. Не вешайте этот класс на кликабельные элементы, иначе они перестанут нажиматься.
* **Графика:** Скругления, тени и градиенты сделаны нативным CSS. Фоновые узоры (7 вариантов) — это SVG `<pattern>` в отдельном слое позади контента. Чтобы паттерн не перехватывал клики, ему задан `z-index: -1`, а контейнерам (`.stage`, `.panel`) — `z-index: 0` для создания локального контекста наложения.
* **Анимации:** Полностью написаны на CSS (`@keyframes` и `transition`). JS только раздает классы (появление интерфейса, пульсация кнопки включения, эффект клика и т.д.). Интерфейс уважает системную настройку "Уменьшить движение" (`prefers-reduced-motion`) и автоматически отключает анимации, если того требует ОС.
